# AI 크리에이티브 — 웹 에디션

『**AI 크리에이티브** — 인공지능으로 만드는 이미지·글·음악·영상』(강영민 지음)의 웹 에디션입니다.

**https://dknife.github.io/AIContents/**

인공지능에 익숙하지 않은 학생, 특히 예술 분야 학생이 인공지능을 이해하고 자기 영역에서
활용할 수 있도록 쓴 교양 교재입니다. 신경망을 만들거나 학습시키는 내용은 다루지 않습니다.
실습에 쓰는 도구는 **무료로 쓸 수 있는 것을 우선**하여 골랐고, 유료로 넘어가면 무엇이
좋아지는지도 함께 밝혀 두었습니다.

## 웹 에디션에서 할 수 있는 것

- **프롬프트 실습 카드** — 본문의 모든 프롬프트에 [복사] 버튼과 [도구에서 열기] 버튼이
  붙습니다. 읽다가 곧바로 도구 창을 열어 결과를 확인할 수 있습니다.
- **토큰 예측 위젯**(3.1절) — 언어 모델이 다음 낱말을 고르는 방식을 온도 손잡이로 체험합니다.
- **확산 위젯**(3.2절) — 노이즈에서 형상이 떠오르는 과정을 단계별로 훑어 봅니다.
- **도구 비교표**(부록 A) — 요금·분야로 걸러 보고 정렬할 수 있습니다.

## 저장소 구조

```
docs/                     ← GitHub Pages 루트
  index.html              ← 랜딩 페이지 (손으로 관리)
  book/
    ch01.html ~ ch13.html ← 본문 (tex2html.py가 생성 — 직접 고치지 말 것)
    apxa.html ~ apxc.html ← 부록 (생성)
    front.html            ← 표지·머릿말 (생성)
    references.html       ← 참고문헌 (생성)
    book.css              ← 스타일 (손으로 관리)
    book.js               ← 프롬프트 복사·체험 위젯 (손으로 관리)
    viewer.html           ← 그림 확대 보기 (손으로 관리)
    data/
      tokens.json         ← 토큰 예측 위젯 데이터 (손으로 관리)
      tools.json          ← 도구 비교표 데이터 (손으로 관리)
    img/                  ← 표지·도식 SVG (build_figures.py가 생성)
```

**`book/*.html`은 원고에서 생성됩니다.** 원고는 별도의 LaTeX 프로젝트에 있으며,
`WebBook/tex2html.py`로 변환해 이 저장소에 씁니다. 여기서 HTML을 직접 고치면
다음 빌드 때 사라집니다.

`book.css` · `book.js` · `viewer.html` · `index.html` · `data/*.json`은
**손으로 관리하는 파일**이라 빌드가 덮어쓰지 않습니다.

## 도구 정보 갱신

이 분야의 서비스 이름·요금·무료 한도는 자주 바뀝니다. 바뀌었을 때는
**`docs/book/data/tools.json`만 고치면** 부록 A의 비교표에 바로 반영됩니다.
원고(.tex)는 건드릴 필요가 없습니다.

프롬프트 카드의 [도구에서 열기] 버튼 목록은 원고 쪽 `WebBook/tex2html.py`의
`TOOL_LINKS` · `CHAPTER_TOOLS`에서 관리합니다.

## 안내

본문에 소개한 인공지능 서비스의 이름·요금·기능은 각 서비스 제공자의 정책에 따라 수시로
바뀝니다. 이 책은 특정 서비스를 보증하지 않으며, 최신 정보는 각 공식 홈페이지에서
확인하시기 바랍니다.
