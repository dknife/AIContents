APPENDIX B

프롬프트 사전

작업 중에 바로 찾아 쓸 수 있도록 프롬프트 어휘를 분류해 모았다. 그대로 베끼기보다, 자기 작업에 맞게 조합하고 자기 목록을 늘려 가는 출발점으로 쓰기 바란다.

이미지: 매체와 화풍

집필 예정유화·수채·과슈·연필·목탄·판화·콜라주·3D 렌더·사진·픽셀아트 등의 영문 표현과 결과 특징.

이미지: 구도와 시점

집필 예정샷 크기, 앵글, 렌즈, 심도, 화면 분할 관련 어휘.

이미지: 조명과 색

집필 예정조명 종류, 시간대, 색조, 대비, 분위기 어휘.

이미지: 품질과 마감

집필 예정해상도·디테일·질감 관련 표현과 과용 시의 부작용.

이미지: 네거티브 프롬프트

집필 예정자주 쓰는 제외 항목과 도구별 지원 여부.

글: 역할과 형식 지시

집필 예정역할 부여, 출력 형식, 길이 제한, 톤 지정 문형.

글: 창작 확장 지시

집필 예정아이디어 확장, 변형, 반전, 제약 추가 문형.

글: 퇴고와 비평 지시

집필 예정문체 교정, 구조 점검, 약점 지적 요청 문형.

음악

집필 예정장르·분위기·악기·템포·시대감 표현.

영상

집필 예정카메라 움직임, 피사체 동작, 전환 표현.

바로 쓰는 템플릿
