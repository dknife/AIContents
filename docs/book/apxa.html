APPENDIX A

무료·유료 도구 총정리

이 부록은 본문에서 소개한 도구들을 한자리에 모아 비교한다. 요금과 무료 한도는 수시로 바뀌므로, 여기서는 각 도구의 성격과 선택 기준에 초점을 맞춘다. 최신 정보는 웹 에디션(https://dknife.github.io/AIContents/)의 도구 비교표를 참고하기 바란다.

도구를 고르는 기준

집필 예정무엇을 만들 것인가, 얼마나 자주 쓸 것인가, 상업적으로 쓸 것인가의 세 질문으로 정리한 의사결정 흐름. 무료로 충분한 경우와 유료가 필요한 경우의 경계.
체험도구 비교표

불러오는 중…

요금 방식과 분야로 걸러 보고, 표 머리를 눌러 정렬해 보자. 이 표의 내용은 웹에서 갱신되므로 책의 서술과 다를 수 있으며, 그럴 때는 웹 쪽이 최신이다.

대화형 AI

집필 예정표: 서비스명 / 무료 범위 / 유료 요금 / 강점 / 이 책에서 쓰는 장.

이미지 생성과 편집

집필 예정표: 서비스명 / 무료 범위 / 제어 기능 / 상업 이용 / 이 책에서 쓰는 장.

음악과 사운드

집필 예정표: 서비스명 / 무료 크레딧 / 상업 이용 조건 / 강점.

영상

집필 예정표: 서비스명 / 무료 크레딧 / 최대 길이 / 해상도 / 강점.

자동화와 기타

집필 예정커스텀 어시스턴트, 노코드 자동화, 파일 변환 등 보조 도구.

유료로 넘어갈 때의 판단

집필 예정월 구독 대 크레딧 구매, 학생 할인, 여러 서비스를 동시에 구독하지 않는 요령, 해지 시점 관리. 취미와 직업의 경계에서 무엇이 달라지는가.
